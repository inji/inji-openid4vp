# Migration Guides

This directory contains migration guides to help you upgrade between different versions of the OpenID4VP SDK.

## Available Migration Guides

- [Migration from 0.7.0 to 1.0.0](MIGRATION_0.7.0_TO_1.0.0.md)

## General Migration Process

When upgrading to a new version of the SDK:

1. Review the migration guide for your target version
2. Check for breaking changes and deprecated features
3. Update your code according to the migration steps
4. Test your integration thoroughly
5. Review the updated documentation for new features

For the latest integration patterns and best practices, refer to the [Integration Guide](../integration-guide.md).
